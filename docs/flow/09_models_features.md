Learn about Gemini Omni models
All users can access Gemini Omni models. The Gemini Omni Flash models offer these exclusive features:
Generate videos at lower cost with Omni 360p: Edit or generate videos from text, frames, or ingredients in 360p at half the credit cost of 720p.
Generate 10s video clips: Generate standard 10s clips in addition to 4s, 6s, and 8s.
Add start & end frames: Define the first and last frames of your video clip.
Important: This feature is currently only available at Google Flow on web.
Edit uploaded and generated videos: Edit uploaded and AI-generated videos with new prompts and ingredients.
Create custom voices: Select a preset voice. Then enter a prompt that describes how you’d like to edit or style it.
Upscale Omni 360p videos: Pro and Ultra subscribers can upscale their Omni 360p video generations to 720p for 0 credits.
Tip: Some Omni features and voice customizations are only available in certain regions. Learn more about Google Flow feature restrictions.
Understand image models & features
To create frames and ingredients for your projects, use one of these image generation and editing models:
Nano Banana Pro: An advanced image model built for complex designs, highly accurate details, and professional-grade control. It is the default model for Google AI Ultra subscribers.
Nano Banana 2 Lite: A highly efficient model for fast, high-quality image generation and editing. It is the default model available at no charge.
Nano Banana 2: The standard model for fast, high-quality image generation and editing.
