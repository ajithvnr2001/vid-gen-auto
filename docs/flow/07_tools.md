Create & manage Tools in Google Flow
Build custom, reusable tools and mini-apps using natural language in Google Flow. You can share Tools publicly and add shared Tools to your library. Google Flow also comes with a preset of Tools supplied by Google.
Important:
Tools are currently available on web & PC only.
Media generated through Tools uses your Google Flow credits. If running a tool might use credits, Google Flow will always display a warning banner.
All media generated by a Tool is automatically saved to the project you currently have open.
Agent queries do not currently cost Google Flow credits,. However, there is a daily quota on how many Tools you can create.
Create a Tool in Google Flow
To build a new Tool, describe your requirements. Google Flow writes the code and builds the tool’s interface for you.
On your device, go to Google Flow.
Click an existing project or start a new one.
On the left, select Tools  Create Tool.
In the prompt box, describe the Tool you want to build.
For example: “Make an image filter app with a slider for grayscale and hue shift.”
Click Generate .
Review the interface & select Save to apply your changes after the agent completes the build.
Open a Tool in Google Flow
On your device, go to Google Flow.
Click an existing project or start a new one.
On the left, select Tools.
At the top, select My Tools.
Select a Tool.
Open a shared link to a Tool
On your device, go to Google Flow.
Select a project to open the Tool in.
Open the shared Tool link.
Edit your Tool in Google Flow
On your device, go to Google Flow.
Open a Tool.
At the top, select Edit.
On the right, describe how you want to adjust the code.
Click Generate .
Change your Tool's icon
On your device, go to Google Flow.
Open a Tool.
At the top right, select More   Edit icon.
Select an image.
Select Save.
Change your Tool's description
On your device, go to Google Flow.
Open a Tool.
At the top right, select More   Edit description.
Edit your Tool's description.
Select Save.
Rename your Tool
On your device, go to Google Flow.
Open a Tool.
At the top right, select More   Rename.
Edit your Tool's name.
Select Check .
Pin, favorite, or remix your Tools in Google Flow
On your device, go to Google Flow.
Open a Tool or a shared link to a Tool.
At the top right, select an action.
To use a Tool globally, select Favorite .
To pin a Tool for quick access within your current project, select  More   Pin.
To create a personal copy of a Tool that you can edit conversationally,  select  More   Remix tool.
Share your Tools
Important: Anyone with the link to your Tool can access the Tool’s code, name, and thumbnail. This applies to any thumbnail images, default or custom.
On your device, go to Google Flow.
Open a Tool.
At the top right, select Share   Copy link.
Share your copied link.
Your link only shares the version of your Tool from when you generated a link to it.
Any edits to your Tool after you generate the link will not be shared with other users.
Tip: To stop sharing a Tool, you must delete it from Google Flow.
