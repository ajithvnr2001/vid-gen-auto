Create & edit images in Google Flow
You can create and edit images directly within your Google Flow projects to use as stand-alone assets or as ingredients for your videos.
Computer AndroidiPhone & iPad
Create an image in Google Flow
Create images with the Google Flow Agent
On your device, go to Google Flow.
Click an existing project.
In the prompt box, turn on Agent.
Learn how to use the Google Flow Agent.
Add a text prompt that describes the image you want to create in detail.
You can ask the Agent to create multiple variations of an image at once.
For example: “Give me 20 variations of this image with different lighting.”
Optional: To add ingredients to your prompt, drag media into the prompt box from your device or project.
Click Generate .
Based on your inputs, the Agent routes your request to the best image model.
Create an image with the standard Google Flow prompt box
On your device, go to Google Flow.
Click an existing project.
In the prompt box, click the model name.
By default, Google Flow sets the model to Nano Banana Pro.
Click Image.
Select your image preferences:
Image aspect ratio.
Number of outputs you want.
The model you want to use. Learn more about Google Flow models and supported features.
Add a text prompt that describes the image you want to create in detail.
Optional: Add ingredients to your prompt.
Learn how to add references to your prompt.
Click Generate .
Learn how to find your images in Google Flow.
Edit an image in Google Flow
When you edit an image in Google Flow, you don’t lose the original image. In the History panel, you can find all previous versions of the image and the prompts you used to generate them.
Edit an image with the Google Flow Agent
On your device, go to Google Flow.
Click an existing project.
In the prompt box, turn on Agent.
Learn how to use the Google Flow Agent.
Drag the images you want to edit into the prompt box, or select multiple images to edit them all at the same time.
Add a text prompt that describes what you want to change.
For example: "Make these black and white."
Click Generate .
Edits are automatically saved to the asset's stack.
Crop an image
On your device, go to Google Flow.
In an existing project, click the image you want to edit.
On the left, click Crop .
Select how you'd like to crop the image.
Click Crop.
Add references to your prompt
Add images to your prompt
On your device, go to Google Flow.
In an existing project, hover over the image.
Click More   Add to Prompt.
Save images to your project
To add a previous version of an edited image in your prompt, save that version to your project first.
On your device, go to Google Flow.
In an existing project, click the image.
On the right, in the History panel, hover over the version you want.
Click Save to Project .
Add characters to your prompt
On your device, go to Google Flow.
Click an existing project or start a new one.
In the prompt box, type @ followed by your character's name.
To add your avatar to your prompt, type @me.
Learn how to create & use your avatar in Google Flow.
Describe how your character should be used as a reference.
For example: @CaptainZoro walking through a futuristic city.
Tip: Learn how to create a character in Google Flow.
