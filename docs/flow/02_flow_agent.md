Use the Google Flow Agent
Brainstorm ideas, refine prompts, get creative suggestions, and guide the generation workflow through natural conversation with the Google Flow Agent, a built-in creative collaborator.
Usage of the Agent is subject to Google’s content policies.
Important:
Google Flow Agent is currently available on web & PC only.
Media generated by the Agent uses your Google Flow credits.
All media generated by the Agent is automatically saved to the project you currently have open.
Agent queries do not currently cost Google Flow credits. However, there is a daily quota on the number of Agent queries.
Turn the Google Flow Agent on or off
Control when you use advanced generative features and chat history.
On your device, go to Google Flow.
Click an existing project or start a new one.
To turn the Agent on, in the prompt box, click Agent.
To open the expanded Agent side panel, click Expand .
To turn the Agent off, click Agent again.
Tip: The Google Flow prompt box changes when the Agent is on. When you turn the Agent off, you’ll return to the standard Google Flow prompt box.
What you can do with the Google Flow Agent
Brainstorm and plan: Chat with the Agent to outline storyboards, develop visual mood boards, and turn high-level concepts into actionable prompts.
Generate new media: Ask the Agent to generate videos or images and select the best model to generate with.
Edit assets directly: Ask the Agent to edit selected media from your project.
Batch generate: Ask the Agent to create multiple variations of an asset at once.
Organize your assets: Ask the Agent to rename specific files, group selected media into a new Collection, or delete unused assets.
Add context & references: Drag media into the Agent prompt box from your device or project. You can also select multiple assets and let the agent know which media you are referring to.
Manage your Google Flow Agent sessions
Important: To manage your sessions, you must turn on and expand the Google Flow Agent.
Your conversations with the Agent are saved automatically as “Sessions.” Sessions are specific to the project you’re working in.
On your device, go to Google Flow.
In your project, at the top of the expanded Agent side panel, click Menu .
Manage your sessions.
To open a past session, click it.
To create a new session, click Create a new session.
Rename a session
At the top of the expanded Agent side panel, click Menu .
Hover over a session.
Click More  Rename.
Delete a session
Important: Deleting a session clears the chat history, but any media generated remains in your assets.
At the top of the expanded Agent side panel, click Menu .
Hover over a session.
Click More  Delete.
Click Delete.
Add instructions for the Google Flow Agent
Important: To add Agent instructions, you must turn on the Google Flow Agent.
To improve consistency in the Agent's behavior across your entire project, add instructions for it.
On your device, go to Google Flow.
At the bottom of your project’s prompt box, click Agent Instructions   Add instruction.
Add a reference image and enter your guidelines for the Agent.
Click Done.
Change default Google Flow Agent settings
Important: To change your default Agent settings, you must turn on the Google Flow Agent.
On your device, go to Google Flow.
At the bottom of your project’s prompt box, click Settings .
Select your default settings.
Choose if Agent confirms before generating: Under “Confirm before generating,” select Always or Never.
By default, the Agent asks for your permission before taking any actions that use your AI credits.
If you select Never, the Agent can generate media and use credits on your behalf without pausing for approval.
Select default image generation settings: Select a default aspect ratio, number of outputs, and image model.
Select default video generation settings: Select a default orientation, number of outputs, and video model.
